# NexusVPS - Modern Cloud VPS Hosting Landing Page

A sleek, responsive, and high-conversion VPS hosting landing page built with vanilla HTML5, CSS3, and JavaScript.

![NexusVPS Preview](https://raw.githubusercontent.com/mehdlk/nexus-vps-landing-page/main/preview.png)

## ✨ Features
- **Hero Section**: Dynamic telemetry diagnostics, live operational network status, and high-impact CTAs.
- **Infrastructure Performance Strip**: Highlighting 99.99% uptime SLA, <30s instant provisioning, 3.2 Tbps DDoS shield, and 24+ global edge datacenters.
- **6 Core Feature Cards**: Gen4 NVMe storage, dedicated AMD EPYC™ cores, KVM isolation, 10Gbps redundant uplinks, custom ISOs, and automated daily snapshots.
- **Interactive Pricing Table**: 4 tiered compute plans (Starter, Pro Compute, Scale Master, Enterprise Node) with an interactive **Monthly / Annual 20% discount switch**.
- **Interactive Custom Resource Sizer**: Real-time sliders for vCPU, DDR5 ECC RAM, and NVMe disk storage with instant live price calculation.
- **Global Datacenter Edge Locations**: Latency overview for 8 primary edge datacenter hubs across NA, EU, and APAC.
- **Responsive & Modern Design**: Dark tech slate aesthetic, fluid layouts for mobile, tablet, and desktop, custom typography (Plus Jakarta Sans & JetBrains Mono).

## 🚀 Quick Start
Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/mehdlk/nexus-vps-landing-page.git
cd nexus-vps-landing-page
```

Open `index.html` directly or host with any static web server / GitHub Pages.
